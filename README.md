# Vrushti Patel: Portfolio

Personal portfolio built with plain HTML, CSS and JavaScript (no framework, no build step).
Multi-page feel through hash routing: Home, Work (with a full Complaint Radar case study), About, Résumé, Contact.

- Live: https://vvrushtii.github.io
- Light and dark theme, animated page transitions, responsive down to phones
- Edit content in `js/main.js` (projects, experience, skills); styling in `css/style.css`
- Résumé PDF: `assets/Vrushti_Patel_Resume.pdf`

Run locally: open `index.html`, or serve the folder with any static server.
